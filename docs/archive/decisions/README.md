# Archived driver decision records

- `0001-driver-ownership.md` — superseded ownership/category proposal.
- `0003-emergency-contacts.md` — proposed emergency-contact table; never implemented.
- `0004-driver-licenses.md` — proposed normalized CA/US license/endorsement/restriction tables; never implemented as written.
- `0005-storage-and-ocr.md` — old document-storage/OCR proposal; OCR architecture is now governed by the shared Document Parser architecture.

For current driver decisions, start at `../../decisions/README.md` and the current driver foundation/schema locks.
