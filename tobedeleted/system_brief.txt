# TRUCKING ERP - CORE INFRASTRUCTURE BIBLE
# Last Updated: 2026-01-02

[ENVIRONMENT]
- Mode: Full Docker Containerization (Docker Compose)
- API Container: trucking_api
- DB Container: shared-postgres

[NETWORKING]
- API Host Access: http://localhost:8001
- API Internal Port: 8000
- DB Port (Internal & External): 5432 (Streamlined as requested)

[DATABASE]
- URL: postgresql+asyncpg://postgres:test_password_123@db:5432/postgres
- Persistence: Docker volume 'postgres_data'
- Protocol: Keep port 5432 for all database operations to ensure easy scaling.

[CODE ARCHITECTURE]
- Multi-tenant: Header 'X-Tenant-ID' required for all requests.
- Business Logic: Tracking Trip Logs (Income), Fuel (Cost), and Maintenance.
- Dashboard Goals: Revenue Per Mile (RPM) and Cost Per Mile (CPM).

[TROUBLESHOOTING]
- DO NOT use port 8000 (Blocked by host ghost processes).
- Restart command: docker-compose restart api
- Logs command: docker-compose logs -f api
