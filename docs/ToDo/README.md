# TruckERP To Do

This folder is the parking lot for TruckERP work that is **pending, deferred, planned for later, or known but not yet resolved**.

Use it for:
- bugs to resolve later
- features to add later
- cleanup or removals to do later
- investigations that are intentionally postponed
- design decisions that still need implementation
- edge cases we do not want to forget

Do **not** use this folder for completed work or for the current proven/gold state of a module.

When an item is completed and verified, remove it from the active To Do list or move it to the appropriate permanent documentation if the history is worth keeping.

Suggested structure:
- `GENERAL.md` — cross-module pending work
- `DL.md` — driver licence/onboarding pending work
- `LOAD_PARSER.md` — load/rate-confirmation parser pending work
- `DISPATCH.md` — trip/dispatch pending work
- additional module files only when needed
